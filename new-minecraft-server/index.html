A new Minecraft server where you only live once

Looking for a new Minecraft server to join? Unborn SMP is a fresh hardcore SMP on Java 1.21.11. Everyone starts at the same time on a brand-new world, with one life each.

Why join a new server now

  1. Everyone starts equal

    No one has years of gear or giant bases yet. Early players claim the best land and found the first factions.

  2. Be part of the first chapter

    The server's lore grows from what players do. The first wars and the first players to fall will be remembered.

  3. A world that never resets

    The map is permanent. What you build stays, even after you're gone.

Questions

When does Unborn SMP open?

Unborn SMP is opening soon. The launch date will be announced in the Discord first.

What version is the server?

Minecraft Java Edition 1.21.11, running on Paper.

Is it free to play?

Yes. You need your own paid copy of Minecraft Java Edition, but joining the server is free, and nothing in a store can buy you an extra life.

What happens if I die?

You become unborn and can't play on the server again. If the death was caused by a bug or lag, you can appeal to staff in the Discord.

How do I join?

Use the address play.unbornsmp.online in Minecraft Java 1.21.11. The How to join page has the full steps.
