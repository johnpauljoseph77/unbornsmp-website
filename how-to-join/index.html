How to join Unborn SMP

Join Unborn SMP (Unborn Universe) at play.unbornsmp.online using Minecraft Java Edition 1.21.11. Read the rules first. You only get one life.

play.unbornsmp.online
The address goes live at launch.

What you need

GameJava Edition

A paid Minecraft account signed in through the official launcher.

Version1.21.11

Choose this release in the launcher before you start.

ModsNone required

Performance mods like Sodium are fine. Cheat clients get you banned.

Join in four steps

  1. Start Minecraft 1.21.11

    Open the Minecraft Launcher, go to Installations, and pick a profile set to release 1.21.11. Press Play.

  2. Add the server

    Click Multiplayer, then Add Server. Type Unborn SMP as the server name. The name only labels the entry in your list.

  3. Enter the address

    Paste play.unbornsmp.online into Server Address. Leave out https://, slashes, spaces and port numbers.

  4. Join, carefully

    Click Done, select Unborn SMP and press Join Server. From this moment your life counts. If you die, you don't come back.

If you can't connect

Unknown host

The address is spelled wrong or has extra text. Type play.unbornsmp.online again with no prefix, slash or port. If it still fails, check the Discord in case the server is down.

Outdated client or server

Your game is on a different release. Set your installation to 1.21.11 in the launcher and start again.

Timed out or connection refused

The server is probably restarting. Wait a minute and try again. You don't need to forward ports on your router.

You are unborn

You died, so the server won't let you play again. If the death was caused by a bug or a false anticheat flag, open a ticket in the Discord. Staff review every appeal and can restore a player.

Still stuck

Post in the Discord support channel with the exact error, your Minecraft version and the address you typed. Hide personal details in screenshots.

Staff will never ask for your Microsoft password, sign-in code or recovery code. If anyone asks, in game or on Discord, it's a scam. Losing your account is the one way to lose your life without dying.
