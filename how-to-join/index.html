Join in four steps

  1. Start Minecraft 1.21.11

    Open the Minecraft Launcher, go to Installations, and choose a profile set to release 1.21.11. Press Play.

  2. Add the server

    Click Multiplayer, then Add Server. Type Unborn Universe as the server name. The name only labels the entry in your list.

  3. Enter the address

    Paste play.unbornsmp.online into Server Address. Leave out https://, slashes, spaces and port numbers.

  4. Join, carefully

    Click Done, select Unborn Universe and press Join Server. From this moment your life counts. If you die, you do not come back.

Troubleshooting

If you can't connect

Unknown hostjava.net.UnknownHostException

The address is spelled wrong or has extra text. Type play.unbornsmp.online again with no prefix, slash or port. If it still fails, check Discord in case the server is down.

Outdated client or server

Your game is on a different release. Go back to the launcher, set your installation to 1.21.11, and start the game again.

Timed out or connection refused

The server is probably restarting. Wait a minute, then try again. You don't need to forward ports on your router to join.

You are unborn

You died, so the server will not let you play again. If you think the death was caused by a bug or a false anticheat flag, open a ticket in Discord. Staff review every appeal and can restore a player.

Still stuck

Post in the support channel on Discord. Include the exact error, your Minecraft version and the address you typed. Hide any personal details in screenshots.
