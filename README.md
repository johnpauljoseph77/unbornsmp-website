# Unborn Universe website

The public site for **Unborn Universe**, a one-life hardcore Minecraft server.
Live at https://unbornsmp.online, hosted on GitHub Pages from the `main` branch.

- `index.html` is the homepage.
- `how-to-join/index.html` is the How to Join page (served at /how-to-join/).
- `assets/site.css` and `assets/site.js` are shared by every page. No build step.
- `CNAME` points GitHub Pages at the custom domain.

To update the site, edit `index.html`, commit and push to `main`. Pages redeploys in about a minute.
